# qtile_personalizado

Esto es un entorno gráfico personalizado creado por Alejandro Yáñez. Este repositorio ha sido creado parcialmente por IA debido a mi falta de conocimientos de python. Este entorno se puede usar sobre ubuntu y se divide en los siguientes archivos:

-assistant.py (posiblemente será remplazado por un asistente de openclaw o de meta ai)
-bar.py
-config.py
-groups.py
-keys.py
-layouts.py
-picom.conf

Hay comentarios en cada archivo sobre como funciona el codigo ;)
